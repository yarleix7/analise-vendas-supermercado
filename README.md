# Análise de Vendas — Supermercado

## Sobre o projeto
Análise exploratória de dados de um supermercado com 3 filiais e 1.000 transações 
registradas entre Janeiro e Março de 2019.

## Objetivo
Identificar padrões de vendas, comportamento dos clientes e oportunidades de melhoria 
para o negócio através da análise dos dados.

## Ferramentas utilizadas
- Python
- Pandas
- Seaborn
- Matplotlib
- Jupyter Notebook

## Principais insights
- Filial Giza gera mais receita com menos transações — maior ticket médio
- Categoria Saúde e beleza tem performance abaixo das demais, concentrada na Filial Alex
- Horário de pico é às 19h
- Janeiro foi o melhor mês em receita ($116.291)
- Clientes Member gastam em média $335 por compra vs $306 dos Normal
- Sábado é o dia com maior receita e ticket médio

## Estrutura do projeto
- `supermercado.ipynb` — notebook com toda a análise
- `SuperMarket Analysis.csv` — base de dados utilizada
